# Frontend

Next.js (App Router) arayüzü.

```
npm install
npm run dev     # http://localhost:3000
```

Ayarlar ortam değişkeniyle verilir ve `lib/config.ts` içinde okunur; liste kök
dizindeki README'dedir. Tarayıcı backend'e doğrudan erişmez: veriyi sunucu
bileşenleri çeker, ekleme ve silme server action'lardan geçer.
